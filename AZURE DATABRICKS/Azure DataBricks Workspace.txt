Login to Azure:

1 In the search bar: Type Databricks to get the Azure DataBricks app. Open it

2 Click on: 		    	 "Create" 
  a) Under Resource Group: 	 
     Click on:              	 "Create New" and name it "databricks-cdea-rg"
  b) Workspace name: 	    	 "databricks-cdea-rg-ws". 
                                  A UNITY CATALOG WITH THE SAME NAME IS CREATED IF YOU LOOK IN THE CATALOG. The UNITY CATALOG contains the Schema, db, volumes.
  c) 			     	  Premium(+ .....)
  d) Workspace Type: 	          Hybrid
  e) Manage Resource Group name: "databricks-cdea-manage-rg"
  f) Click on: 			 "Preview + Create"
  g) Click on: 			 "Create"
  


3 Once the deployment is complete open the workspace
  a) Go to:         "Resource Groups"
     Click on the:  "databricks-cdea-rg": and click on the newly created workspace "databricks-cdea-rg-ws"
  b) Click on the:  Launch workspace button
  c) Click on the:  email account






<<<<<<<<<: CREATE A COMPUTE (Login to Azure DataBricks Workspace)


 1 Go to "Compute"/ All-Purpose compute
   a) Click on: 		    	 "Create Compute" 
   b) Computer name:                      Choose a name
   c) Policy:                             Unrestricted
   d) Machine Learning:                   Check it
   e) DataBricks runtime:                 17.3 LTS  LONG TIME SUPPORT
   f) Photon Acceleration:                Uncheck
   g) Click on:                           Create






<<<<<<<<<: LINK A GIT REPO TO A GIT folder in the WORKSPACE (Login to Azure DataBricks Workspace)
 1 Go to "Home"
   a) Click on: 		    	 "Create" 
   b) Click on: 		    	 "Git Folder"

   Fillin the next fields:
   Git Repository: copy/paste the repo url with the 'git' extension
   Git Provider: GitHub
   Git folder name: Usually the name of the repo is taken bydefault from the repo url as this name but you can choose a desired one.
